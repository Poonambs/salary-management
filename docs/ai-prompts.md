# AI Usage and Prompts

AI tools were used intentionally during development as an engineering assistant.

## How AI Was Used

AI assistance was used for:

- Breaking the assessment into incremental development steps
- Designing the database structure
- Generating initial Spring Boot entity and repository structures
- Reviewing API design
- Troubleshooting Angular rendering and change-detection issues
- Improving frontend filtering logic
- Reviewing architecture and scalability considerations
- Creating documentation

## Example Prompts

### Database Design

"Design a relational database schema for an employee salary management system supporting approximately 10,000 employees."

### Backend Design

"Create a clean Spring Boot structure using controller, service, repository, entity and DTO layers for an employee salary management application."

### Frontend

"Create an Angular employee management page that displays employees with country and department filters."

### Debugging

"Help diagnose why Angular receives employee data from the API but the table does not consistently update."

### Code Review

"Review this implementation for readability, maintainability, performance and potential issues."

## Human Review

AI-generated suggestions were reviewed and tested before being included in the application.

The final implementation decisions, debugging, testing and integration were performed as part of the development process.
